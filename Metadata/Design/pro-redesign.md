# SplitCam Pro — 双镜头光环

本轮按附件的「动态顶部、权益、套餐、固定购买区域」关系重做，采用深色光学视窗与暖白内容面。视觉符号来自双摄和分屏，不复制附件应用的宇宙漩涡、品牌标识或折扣文案。

顶部为原生 SwiftUI Canvas 动效：青色与紫色镜头以 12 秒周期在左右、上下和大小画中画三种构图间转换。细环高光与少量光点缓慢移动，四角取景框保持稳定；30 fps 上限，后台暂停，“减少动态效果”显示静态构图。无视频下载，也不打包动画视频。

中部标题「双重视角，让故事更完整。」与三项实际 Pro 权益相连：画中画视频、视频合拍、专属图标。触发来源仅加粗对应权益，不虚标 NEW。

月度/年度并排，终身方案独立一行；大字号时订阅卡纵向排列。默认选年度，具体价格以 StoreKit 为准。年费节省比例按同币种月费 × 12 计算，低于或等于 0 不显示。试用只在 StoreKit 确认资格后展示。

购买按钮、当前方案计费说明、恢复购买、条款与隐私固定在底部。恢复购买从设置页移除，Pro 页可完成恢复并显示结果/错误。网络无法加载套餐时有重试与关闭入口。

四款新图标：Chrome 液态银、Terrazzo 陶石、Blueprint 蓝图、Bloom 花绽。全部 Pro 专属，列表入口与实际切换方法均检查权限。注册 Debug/Release 的 alternate icons，并保留原有图标。

Custody Journal 图标来源：Apple iTunes Lookup，app id 6762594124，于 2026-09-13 取得 artworkUrl512 并打包为本地资源，设置页离线也能显示。

版本号与 build 仍沿用当前工程 1.7 (8)；本轮没有自动选择新的发布版本或上传 ASC。新的更新内容另存现有 metadata 文案，待确定发布版本后使用。
